# 🐻 Оператор МЕДВЕДЬ - Симулятор доставки грузов

## 📦 Урок 5: Грузовая доставка

3D-тренажёр управления грузовым дроном с физикой подвешенного груза и ветровыми нагрузками.

### 🎮 Управление
- **WASD / Стрелки** - горизонтальное движение
- **Q / Shift** - набор высоты
- **E / Ctrl** - снижение
- **Зажать ЛКМ** - сбросить груз в зоне доставки

### 🎯 Задача
Доставить 5 грузов в горные районы за 4 минуты, учитывая:
- Ветер (меняется каждые 3 секунды)
- Качание груза как маятник
- Ограниченное время

### 🚀 Демо
[Запустить симулятор](https://ВАШ_ЛОГИН.github.io/medved-drone-simulator)

### 🛠 Технологии
- Three.js r128
- WebGL
- Чистый JavaScript

### 📱 Совместимость
- Работает на ПК и мобильных устройствах
- Требуется поддержка WebGL
