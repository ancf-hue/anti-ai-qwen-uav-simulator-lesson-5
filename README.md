## 📖 О проекте

**«Оператор МЕДВЕДЬ»** — это интерактивный 3D-тренажёр, в котором вы управляете грузовым дроном, доставляющим медикаменты в горные районы. Тренируйте реакцию, точность и навыки пилотирования в условиях ветра, турбулентности и качающегося груза.

🎯 **Урок 5: Грузовая доставка** — пятый модуль серии тренажёров.  
Дрон с подвешенным грузом ведёт себя как настоящий: груз качается как маятник, ветер сносит аппарат, а приземление требует ювелирной точности.

---

## ✨ Особенности

- 🎮 **Реалистичная физика** — груз на тросе ведёт себя как маятник, инерция, снос ветром
- 🌬️ **Динамический ветер** — скорость и направление меняются в реальном времени
- 📦 **5 зон доставки** — нужно точно приземлиться в каждой из них
- 🎚️ **3 уровня сложности**:
  - 🟢 **Лёгкий** — слабый ветер, широкая зона, стабильный груз
  - 🟡 **Средний** — умеренный ветер, стандартные условия
  - 🔴 **Сложный** — шторм, узкая зона, сильно качающийся груз
- 🎨 **3D-кнопки с эффектами** — объёмные, с анимацией нажатия и свечением
- 🔊 **Звуковые эффекты** — синтезированные через Web Audio API
- 📱 **Адаптивный дизайн** — работает на ПК и мобильных устройствах
- 🌐 **Полный офлайн** — не требует интернета после загрузки
- 🎯 **Система захвата цели** — удерживайте прицел 2 секунды для сброса груза

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `W` / `↑` | Движение вперёд |
| `S` / `↓` | Движение назад |
| `A` / `←` | Движение влево |
| `D` / `→` | Движение вправо |
| `Q` / `Shift` | Набор высоты |
| `E` / `Ctrl` | Снижение |
| **ЛКМ (удерживать)** | Сброс груза (в зоне доставки) |

> 💡 Поддерживается русская и английская раскладка клавиатуры.

## 🛠️ Технологии

- **Three.js r128** — 3D-рендеринг через WebGL
- **Web Audio API** — синтез звуков без внешних файлов
- **Vanilla JS** — без фреймворков, чистый JavaScript
- **CSS3** — анимации, 3D-эффекты кнопок, адаптивная вёрстка
